# قلمرو جاودان (Eternal Realm)

ربات بازی نقش‌آفرینی اجتماعی برای گروه‌های **بله**. هر بازیکن یک شخصیت دائمی دارد که در همه‌ی گروه‌ها یکسان است
(سطح، سکه، تجهیزات). بازی اصلی داخل گروه‌ها با پیام‌های فارسی انجام می‌شود: بنویس «ماهیگیری»، یا روی پیام کسی
ریپلای کن و بنویس «مبارزه».

ساخته‌شده با [Baleropy](https://github.com/rezamardani01/Baleropy) و SQLite.

## راه‌اندازی (ویندوز یا لینوکس)

```bash
python -m venv .venv
.venv\Scripts\activate                  # ویندوز  (لینوکس: source .venv/bin/activate)
pip install -r requirements.txt
copy config.example.toml config.toml    # لینوکس: cp
```

در `config.toml` دو مقدار را پر کن:

```toml
[bot]
token = "توکن ربات از @botfather"
owner_id = 123456789        # شناسه عددی خودت (مالک ربات)
```

```bash
python main.py
```

دیتابیس (`data/game.db`) و جدول‌ها خودکار ساخته می‌شوند. فایل `config.toml` و پوشه `data/` در گیت نادیده گرفته می‌شوند.

## بازی چطور کار می‌کند

1. بازیکن در پیام خصوصی ربات `/start` می‌زند، **نام نمایشی** می‌نویسد، **نژاد** (۶ نژاد) و **کلاس** (۵ کلاس) را انتخاب می‌کند.
2. ربات را به گروه اضافه می‌کنند (برای پاسخ به پیام‌های فارسی، ربات باید پیام‌های گروه را ببیند).
3. در گروه با کلمه‌های فارسی (یا `/دستور`) بازی می‌کنند.

### دستورهای گروه (فقط چند کلمه‌ی پایه)

| بنویسید | کار |
|---|---|
| ماهیگیری / معدن / گیاه / جستجو / شکار | فعالیت‌های انرژی‌بر |
| استراحت · جایزه | انرژی و گنجینه‌ی روزانه |
| مبارزه (ریپلای روی پیام کسی) | دوئل نوبتی با دکمه |
| پروفایل (با ریپلای: قهرمان دیگران) | مشخصات |
| قلمرو | پنل اصلی (همان `/start`) با دکمه‌ها |
| احضار باس · باس | باس گروهی: ۲۰۰ سکه، از سطح ۳. همه با «پیوستن» ثبت‌نام می‌کنند، احضارکننده «شروع» را می‌زند و نبرد **خودکار** (دور به دور بر اساس کلاس هر نفر) روی همان پیام گزارش می‌شود؛ پاداش به نسبت سهم هر نفر |
| رویدادها | رویدادهای تصادفی گروه: صندوقچه‌ی اسرارآمیز، تاجر دوره‌گرد، ستاره‌ی تجربه (تجربه‌ی دوبرابر) و باس مخفی (رایگان؛ هر جنگجو می‌تواند شروع کند). ربات هر چند ساعت خودش در گروه‌های فعال رویداد می‌سازد؛ مدیران با «غیرفعال رویدادها» خاموشش می‌کنند و با `/event` یکی را فوراً می‌خواهند. تازه‌واردها هم با پیام خوش‌آمد روبه‌رو می‌شوند |
| خاندان · کلن | پنل خاندان با دکمه‌های شیشه‌ای: فهرست و پیوستن، اعضا، مقام‌دادن (رهبر، معاون، ریش‌سفید، عضو)، اخراج، واگذاری رهبری، باز/بسته کردن در، خزانه و سطح خاندان (هر سطح جای بیشتر)، برترین خاندان‌ها |
| ساخت خاندان نام | ساخت خاندان (۱٬۰۰۰ سکه) · «دعوت خاندان» با ریپلای روی پیام یک نفر، دکمه‌ی پذیرش فقط برای خود او |
| رتبه ← لیگ | دوئل‌ها امتیاز لیگ (الو) می‌دهند: برنز، نقره، طلا، الماس، اسطوره‌ای · «جنگ خاندان‌ها» در پنل خاندان: امتیاز هفتگی از برد دوئل و باس، جایزه‌ی سه خاندان برتر هفته‌ی پیش |
| تجهیزات ← یک قطعه | ست تجهیزات (آهنین، چرمی، اژدهاکُش): با پوشیدن ۲ یا ۳ یا ۴ قطعه بونوس می‌گیرید · هر قطعه تاریخچه دارد (غنیمت کدام باس، صاحبان قبلی)؛ باس‌ها بعد از شکست گاهی قطعه‌ی ویژه می‌دهند |
| پیوند سلاح | سلاحِ دست‌شما با هر شکار (۱)، دوئل (۲) و باس (۳) به شما نزدیک‌تر می‌شود: غریبه ← آشنا ← یار ← هم‌خون؛ هر سطح ۵٪ توان خود سلاح را بیشتر می‌کند و در صفحه‌ی همان قطعه دیده می‌شود |
| داستان · مأموریت | داستان‌های زنجیره‌ای با دکمه: هر انتخاب صحنه‌ی بعد و پایان را عوض می‌کند، بعضی راه‌ها فقط با انتخاب‌های قبلی باز می‌شوند، هر داستان یک بار پاداش می‌دهد |
| آلبوم · کارت · کلکسیون | آلبوم کارت‌ها (قهرمانان، هیولاها، اژدهایان، مکان‌ها، افسانه‌ها): کارت از شکار و باس‌ها و بسته‌ی کارت (۱٬۵۰۰ سکه با شانس‌های نمایان، بدون خرید تصادفی با پول واقعی) · کارت تکراری فروخته می‌شود · کامل کردن هر مجموعه = عنوان و کریستال · کارت‌ها قدرت رزمی ندارند |
| آلبوم ← بازار کارت | خرید و فروش کارت تکراری بین بازیکنان با سکه (کارمزد ۵٪، فیلتر کمیابی، قیمت با دکمه‌های ± و صفحه‌ی تأیید)؛ آخرین نسخه‌ی هر کارت همیشه در آلبوم می‌ماند |
| حیوان همراه · پت | حیوان همراه با بونوس کوچک آماری (فقط یکی فعال): گربه و شاهین با سکه، روباه و گرگ و ققنوس از «خزانه‌ی ویژه» با پول واقعی (محتوای ثابت، بدون شانس؛ خرید دوباره بلاک است) |
| سیاه‌چال | پنج اتاق پشت‌سرهم (هیولا، گنج، تله، چشمه‌ی شفا) با نگهبان در آخر؛ جان از اتاقی به اتاق دیگر می‌ماند، ۳۰ انرژی، هر ۲ ساعت یک بار · شکست = نصف گنج، پیروزی = همه‌ی گنج و صندوقچه‌ی جادویی |
| کوره · آهنگری | ساخت تجهیزات افسانه‌ای (شمشیر آتشین، زره اژدها، خنجر سایه، عصای کریستالی، اجزای ست اژدهاکُش): یک تجهیزات پایه + مواد کمیاب + سکه، با صفحه‌ی تأیید و فهرست آنچه کم دارید |
| خزانه‌ی ویژه ← خدمات | برگه‌ی تغییر نژاد، کلاس و نام (پول واقعی)؛ مصرف از «شخصیت من ← ارتقای قهرمان ← خدمات» و «تغییر نام نام‌تازه»، همیشه با صفحه‌ی تأیید |
| قهرمان من ← مسیر قهرمانی | «بلیط مسیر قهرمانی» فصلی (۴۵ روز، ۱۰۰ مرحله): پنل شیشه‌ای هر مرحله با ستون «رایگان | طلایی» و دکمه برای هر جایزه (سکه، کریستال، آیتم، کارت کلکسیونی، عنوان)، «مرحله بعدی/قبلی»، پیام خصوصی هنگام رسیدن به مرحله‌ی تازه با دکمه‌ی «دریافت جوایز» (بدون بلیط فقط رایگان)؛ بلیط ۴۹٬۹۰۰ تومان و اختیاری است |
| پیشنهادها | موتور پیشنهاد شخصی: قوانین نام‌دار و امن (بازگشت پس از ۷ روز، کارت‌های کم‌مانده، جایزه‌ی آماده، کلاس دوم، سکه‌ی زیاد، ...) با حداکثر ۱ پیام در روز، زمان انتظار برای هر قانون و کلید خاموش/روشن برای هر بازیکن؛ فقط پیام خصوصی |
| مأموریت‌های امروز | ۳ مأموریت شخصی در روز، انتخاب‌شده بر اساس سطح و وضعیت (خاندان، سکه، شکست‌ها)، با پاداش سکه و ۲۰ امتیاز مسیر قهرمانی؛ شمارش با همان اعمال بازی (شکار، دوئل، باس، کارت...) |
| شخصیت من ← ارتقای قهرمان | کلاس دوم (از سطح ۱۵، ۳٬۰۰۰ سکه): نیمی از توان یک کلاس دیگر · بیداری قدرت (از سطح ۲۰، ۵٬۰۰۰ سکه و ۲۰ کریستال): بونوس نژاد دو برابر و ۱۰٪ توان بیشتر |
| راهنما | پنل شیشه‌ای راهنما با یک صفحه برای هر بخش |
| کوله‌پشتی · تجهیزات · صندوقچه · فروشگاه · بازار · ماجراجویی · رتبه | باز کردن پنل شیشه‌ای همان بخش |
| رتبه | تالارها با دکمه‌ی شیشه‌ای: سطح، ثروت، دوئل، شکارچیان باس (کل آسیب)؛ در گروه هم «این گروه»، «قهرمان هفته» (بیشترین آسیب به باس‌ها در ۷ روز) و «تاریخچه‌ی نبردها» (آخرین باس‌ها با تاریخ شمسی، نتیجه و بیشترین آسیب‌زننده) |
| کیف من · اطلاعات من | دکمه‌ی ورود به پنل شخصی در پیوی |
| انتقال مبلغ (ریپلای) | بخشش سکه |
| راهنما | فهرست دستورها |

**هر چیز دیگر (پوشیدن، خرید، فروش، ارتقا، باز کردن صندوقچه، عرضه در بازار ...) فقط با دکمه‌ی شیشه‌ای است.**
هر پنل پیام خودش را ویرایش می‌کند و فقط صاحبش می‌تواند دکمه‌هایش را بزند (حتی وقتی در گروه باز شده باشد).

مدیران گروه: «غیرفعال ماهیگیری»، «فعال ماهیگیری»، «غیرفعال بازی»، «تنظیمات گروه».

### پنل مالک (فقط پیام خصوصی، فقط `owner_id` و `admin_ids`)

`/admin` · `/stats` · `/givegold` · `/givecrystal` · `/giveitem` · `/setlevel` · `/ban` · `/unban` · `/broadcast` · `/backup`.
همه‌ی کارها در جدول `admin_log` ثبت می‌شوند.

## پرداخت با کیف پول بله

بسته‌های سکه، کریستال و ویژه در «فروشگاه ویژه» (پیام خصوصی) با `sendInvoice` بله فروخته می‌شوند.
مسیر امن: سفارش `pending` ← تأیید `pre_checkout` (کاربر، مبلغ و مهلت بررسی می‌شود) ← `successful_payment` ←
پرداخت و تحویل در **یک تراکنش**؛ تکرار همان پیام پرداخت دوباره چیزی تحویل نمی‌دهد. اطلاعات کارت هیچ‌جا ذخیره نمی‌شود.

- برای تست: `provider_token = "WALLET-TEST-1111111111111111"` (پیش‌فرض).
- برای انتشار واقعی توکن پذیرنده‌ی کیف پول بله را در `[payments]` بگذار.
- قیمت‌ها و محتوای بسته‌ها: `eternal_realm/game/data/packs.py` (قیمت به **ریال**).
- فروش پولی را می‌شود با `enabled = false` خاموش کرد.

> صندوقچه‌های جادویی/سلطنتی با **کریستال** خریده می‌شوند (و کریستال را می‌شود با پول واقعی خرید). شانس هر جایزه
> با «شانس صندوقچه جادویی» برای همه قابل مشاهده است. اگر قانون یا سیاست پلتفرم، صندوقچه‌ی شانسی پولی را برای
> کاربران زیر ۱۸ سال محدود می‌کند، قبل از انتشار آن را بررسی کن.

## معماری

```
Bale ← Baleropy ← bot/ (handlers، دکمه‌ها، نمایش)
                    ↓
              game/services   ← منطق بازی (هر قابلیت یک سرویس)
                    ↓
              game/engine     ← محاسبه‌ی خالص (مبارزه، غنیمت، سطح)
                    ↓
              db/repos        ← تنها جایی که SQL می‌نویسد
                    ↓
              SQLite (یک اتصال + قفل + تراکنش BEGIN IMMEDIATE)
```

- `bot/commands/` : یک رجیستری مرکزی برای همه‌ی دستورها؛ هر قابلیت فقط `@command(...)` می‌گذارد.
- `game/data/` : داده‌ی خالص (نژاد، کلاس، آیتم، فعالیت، هیولا، صندوقچه، بسته). فعالیت جدید = یک ورودی جدید.
- `config.py` : همه‌ی ضرایب بازی در `Balance` هستند و از `config.toml` قابل تغییرند.
- همه‌ی عملیات مالی با تراکنش و دفتر کل (`transactions`) انجام می‌شوند؛ پاداش دوئل، خرید بازار و تحویل سفارش با
  «شناسه یکتا + تغییر وضعیت یک‌بار» از تکرار محافظت شده‌اند.
- هنگام نوشتن سرویس جدید: **داخل `async with db.transaction()` سرویس دیگری را صدا نزن** (قفل دیتابیس تودرتو نیست)؛
  از توابع `...in(tx, ...)` یا مخزن‌ها استفاده کن.

## پشتیبان‌گیری و تست

- هر ۲۴ ساعت یک نسخه‌ی پشتیبان در `backups/` ساخته می‌شود (۷ تای آخر نگه داشته می‌شود). دستی: `python scripts/backup.py` یا `/backup`.
- برای مهاجرت به PostgreSQL در آینده فقط لایه‌ی `db/` باید عوض شود.

```bash
pip install -r requirements-dev.txt
pytest
```

تست‌ها شامل رفتار کامل ربات با به‌روزرسانی‌های ساختگی بله، رقابت هم‌زمان خریداران، پرداخت تکراری و سقف‌هاست.

## چیزهایی که هنوز ساخته نشده

موجودات همراه و تخم، انجمن‌ها (Guild) با گروه رسمی، مأموریت‌ها و دستاوردها، رویدادهای تصادفی و باس گروهی،
معجون‌سازی، مناطق جهان. ساختار برای افزودن آن‌ها آماده است (داده‌محور + سرویس مستقل).
